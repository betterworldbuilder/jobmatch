# Feedback log

Every reply, call or user comment, appended via `/log` (newest at the bottom). All agents read this before working.
Never record personal emails or phone numbers: use company name or person's role only.

- `source`: reply | call | user comment | investor
- `filed to`: which doc(s) also got the insight (`docs/objections.md`, `docs/icp.md`, `data/leads.csv`, or `-`)
- `action`: the next step it triggers (follow-up draft, fix, script change, or `none`)

|---|---|---|---|---|---|
